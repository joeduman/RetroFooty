TEAMBALL 14.0.1 - QUICK GAMEPLAY / VISUAL HOTFIX
============================================

Patch changes (based on the provided Build 14.0 Competitive AI ZIP):

- Goal netting is no longer solid to players; goalposts remain physical.
- Expand arena runoff from 64 to 96 world units so a whole player can pass
  behind the back net within the visible green arena, and return to play.
  The BALL still collides with physical net walls and posts.
- The ball continues moving, spinning, rebounding, and colliding throughout
  the scored-goal celebration. Scoring happens once. The match timer and
  statistics stay paused during the celebration. Park walking does not gain
  a hidden collidable ball.
- 3v3 / 4v4 / 5v5 pitch width and height are each 7% larger (rounded).
  1v1 and 2v2 pitch dimensions are unchanged. AI policy/trainer unchanged.
- Dark outside-pitch canvas band is now field green. The big black rectangle
  behind GOAL, kickoff numbers, practice countdown and FULL TIME is removed.
  Main match HUD and help text backgrounds are also transparent.
- Post-game shot map plots the start and observed path of actual shots,
  highlighting scored shots in gold and stopping their path at the mouth.
  Existing stats, heatmaps, and archived replays are still available.

QUICK PATCH (recommended for a working Build 14.0 installation)
1. STOP the running game using STOP-TEAMBALL.cmd. Do not patch live code.
2. Back up your Teamball-14.0 folder (especially bot-memory and server-data).
3. Extract the separate Hotfix-Patch ZIP and copy its contents into the
   existing Teamball-14.0 game folder, preserving relative subfolders.
   Agree to replace the existing CODE files. DO NOT replace bot-memory,
   server-data, training settings, or accounts; none are included in patch.
4. Launch START-TEAMBALL.cmd and hard-refresh browser (Ctrl+Shift+R).

FULL ZIP
1. Extract to a NEW folder, do not run two copies of the server at once.
2. Copy your existing 'bot-memory' and optionally 'server-data' folders into
   this new game folder AFTER extracting the ZIP. Keep them private.
3. Start the game using START-TEAMBALL.cmd.
