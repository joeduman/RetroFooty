BROWSER TEST STATUS
- Automated Chromium navigation to the local server was blocked by the
  test environment. GUI gameplay, account dashboard visuals, Windows CMD
  startup, real user-hosting throughput and external-network latency remain
  unverified and should be playtested on the user's machine.
- The source modules pass Node syntax checks, and existing Node-based
  park-network, online-room, physics and client-logic tests are all passing.

IMPORTANT LIMITATIONS
- Learning is bounded tactical adaptation and self-play policy search, not
  a trained deep reinforcement learning model or direct learning from YouTube.
- Remote public HTTP email/password registration is disabled pending HTTPS.
- Email verification, SMTP delivery, account recovery, global leaderboards
  and high-quality human-versus-bot competitive benchmarks are future work.
- Opt-in human data from online park and private rooms is recorded; local
  browser-only sessions do not upload human inputs to the server.
