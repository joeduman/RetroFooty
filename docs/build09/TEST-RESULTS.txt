The new build produced more goals and sprinting, fewer completed passes, and more own
goals in total. This supports increased aggression, not a blanket teamwork improvement.
Own-goal share in this sample was approximately 11.1% vs 11.3% of all goals.
The dangerous-kick ray heuristic remained 0 in both samples; it does not cover later
deflections or guarantee safe physical touches. Bots still make mistakes.

Limits
The supplied Teamball 2 montage was inspected directly; Help(7).mp4 was transcribed.
Exact original acceleration/drag values are not claimed from panning, edited footage.
These checks validate functionality and stability, not human enjoyment or perfect tactics.
Replays store visible states at 20 Hz with interpolation, plus reports, in this browser.
They are not screen recordings. Early exits through the game UI are saved; crashes may
lose the last 15 seconds since a checkpoint. Browser storage and site-data retention apply.
Browser tests used headless Chromium on Linux. Visual checks cover match, practice, report,
history and replay screens; mobile geometry is checked. An optional modal screenshot
timed out with GPU effects, so the dedicated visual capture disables backdrop blur only.
Sound is checked as a bounded nonzero waveform with a clean ending. Subjective speaker
playback is not claimed. Native Windows .cmd and PowerShell execution was unavailable;
those files were inspected as text. Node startup and authenticated stop ran on Linux.
